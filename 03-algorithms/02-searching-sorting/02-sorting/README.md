# Sorting

## Key Topics
- Comparison vs. non-comparison sorts
- Stability and in-place definitions
- Time/space trade-offs across algorithms
- Adaptive and hybrid sorts (TimSort, intro sort)

## Must-Implement
- Bubble, insertion, selection sort (baseline)
- Merge sort and quick sort
- Heap sort
- Counting sort, radix sort, or bucket sort (for integer keys)

## Practice Problems
- Sort colors (Dutch national flag)
- Wiggle sort
- Largest number (custom comparator)
- Reorder data in log files

## Self-Check
- When is counting sort applicable?
- How do pivot strategies affect quick sort?
- Why is merge sort stable but not in-place?
