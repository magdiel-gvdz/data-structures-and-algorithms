# Searching & Sorting

These are foundational routines that appear as subroutines in many problems. Understand their mechanics, complexity, and failure modes.

## Topics Covered
- Searching: linear, binary, ternary, interpolation
- Sorting: comparison-based vs. non-comparison-based
- Stability, in-place behavior, best/worst-case performance
- Selection algorithms (quickselect, heapselect)

## Study Plan
1. Review searching strategies in `01-searching/`.
2. Expand to sorting algorithms in `02-sorting/`.
3. Benchmark implementations and visualize their behavior.

## Practice Ideas
- Instrument code to count comparisons and swaps.
- Sort large random arrays and measure runtime.
- Apply binary search to monotonic predicate problems.

Document lessons learned in the subdirectory READMEs.
