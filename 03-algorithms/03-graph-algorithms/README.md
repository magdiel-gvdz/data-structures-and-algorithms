# Graph Algorithms

Graphs model relationships and networks. Combine the data-structures knowledge from `02-data-structures/02-non-linear/04-graphs` with algorithmic techniques here.

## Core Topics
- Traversals: BFS, DFS, iterative deepening
- Shortest paths: Dijkstra, Bellman-Ford, Floyd-Warshall
- Minimum spanning tree: Kruskal, Prim
- Network flow: Ford-Fulkerson, Edmonds-Karp (stretch goal)

## Must-Implement
- Dijkstra with a priority queue
- Bellman-Ford for negative edges
- Union-Find based Kruskal
- Topological sort and cycle detection
- Optional: A* pathfinding on grid graphs

## Practice Problems
- Network delay time
- Cheapest flights within K stops
- Reconstruct itinerary (Eulerian path)
- Max area of island (grid DFS/BFS)

## Self-Check
- When do you need to guard against negative cycles?
- How do you choose between Dijkstra and Bellman-Ford?
- What is the complexity of each algorithm based on graph density?
