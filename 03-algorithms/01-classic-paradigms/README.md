# Classic Paradigms

The paradigms in this directory represent reusable blueprints for solving broad classes of problems. Study them sequentially and focus on the decision-making process that leads you to each approach.

## Topics Covered
- `01-divide-and-conquer/`
- `02-dynamic-programming/`
- `03-greedy/`
- `04-backtracking/`

## Study Routine
1. Read the overview README for the paradigm.
2. Walk through at least two canonical examples by hand.
3. Implement a template or helper functions you can reuse.
4. Solve problems ranging from easy to hard, capturing takeaways in `04-practice/01-patterns`.

## Reflection Checklist
- What signals in a problem statement point to this paradigm?
- What are the key subproblems or choices?
- How do you prove correctness or optimality?
- Where do common pitfalls arise (e.g., overlapping subproblems, greedy choice failures)?

Revisit these notes before mock interviews or contests to refresh strategies quickly.
