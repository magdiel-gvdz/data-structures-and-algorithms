# Dynamic Programming

## Core Ideas
- Optimal substructure and overlapping subproblems
- State definitions and transitions
- Memoization vs. tabulation
- Space optimization (rolling arrays)

## Must-Implement
- Fibonacci (memoized and bottom-up)
- 0/1 knapsack
- Longest increasing subsequence (n log n approach as stretch goal)
- Edit distance (Levenshtein)

## Practice Problems
- Coin change (min coins and total combinations)
- Longest common subsequence
- House robber (linear and circular variants)
- Word break

## Self-Check
- Can you define states, decisions, and base cases quickly?
- How do you derive transitions from brute-force recursion?
- When can you reduce space complexity to O(1) or O(k)?
