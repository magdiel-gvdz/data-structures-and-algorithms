# Greedy Algorithms

## Core Ideas
- Make the locally optimal choice hoping for global optimality.
- Prove correctness via exchange argument or matroid/optimal substructure reasoning.
- Understand counterexamples where greedy fails.

## Must-Implement
- Interval scheduling / activity selection
- Huffman coding tree
- Minimum spanning tree (Kruskal and Prim)
- Dijkstra's shortest path (with a priority queue)

## Practice Problems
- Gas station (circular tour)
- Jump game (reachability)
- Fractional knapsack vs. 0/1 knapsack comparison
- Task scheduling with deadlines and profits

## Self-Check
- What proof technique justifies your greedy choice?
- How do you detect when greedy is insufficient?
- How do data structures (heaps, sets) support greedy strategies efficiently?
