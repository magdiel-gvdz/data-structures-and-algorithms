# Divide and Conquer

## Core Ideas
- Split the problem into independent subproblems.
- Solve subproblems recursively.
- Combine results to form the final answer.
- Analyze using recurrence relations.

## Must-Implement
- Merge sort
- Quick sort (with discussion on pivot selection)
- Binary search variants (first/last occurrence)
- Closest pair of points (stretch goal)

## Practice Problems
- Count inversions in an array
- Kth smallest element using quickselect
- Fast exponentiation (power function)
- Skyline problem (advanced)
