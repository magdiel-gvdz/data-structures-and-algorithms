# Algorithms Overview

Algorithms complement your understanding of data structures. Focus on mastering paradigms, not memorizing solutions.

## Study Order
1. `01-classic-paradigms` - Core strategies that appear across problems.
2. `02-searching-sorting` - Bread-and-butter procedures with frequent interview use.
3. `03-graph-algorithms` - Real-world applications ranging from routing to recommendation systems.

## Learning Goals
- Recognize which paradigm applies to a new problem.
- Develop an intuition for time/space trade-offs.
- Be comfortable deriving recurrences and solving them with the Master Theorem.
- Code solutions cleanly while handling edge cases.

## Practice Tips
- Re-implement algorithms without copying code. Explain each line in comments or aloud.
- Visualize recursion trees and state transitions when debugging.
- Compare iterative vs. recursive forms and discuss pros/cons.

Use the subdirectory READMEs for detailed checklists and problem sets.
