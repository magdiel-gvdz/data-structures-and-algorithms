# Roadmap

Use this roadmap as a guide. Adjust pacing based on your available time and prior experience. Each phase builds on the previous one--do not rush past fundamentals.

## Phase 0: Setup (1 day)
- Pick a primary programming language and set up tooling (IDE, formatter, debugger).
- Review the repository map in the root `README.md`.
- Schedule recurring study blocks and block off weekly review time.

## Phase 1: Foundations (1-2 weeks)
- Work through `01-foundations/README.md`.
- Rehearse time and space complexity analysis until you can do it from memory.
- Implement simple algorithms (sum, max, reverse list) and profile them.

## Phase 2: Core Data Structures (3-4 weeks)
- Follow the order in `02-data-structures/README.md`.
- For each data structure: read the overview, implement it from scratch, then answer the self-check questions.
- Build a small project combining multiple structures (e.g., a task scheduler using heaps and hash tables).

## Phase 3: Algorithm Paradigms (4-5 weeks)
- Dive into `03-algorithms/01-classic-paradigms`.
- Focus on one paradigm per week. Solve at least 10 problems per paradigm, split evenly between easy and medium difficulty.
- Document insights and reusable patterns in `04-practice/01-patterns`.

## Phase 4: Graphs & Advanced Topics (2-3 weeks)
- Cover `03-algorithms/03-graph-algorithms` and revisit relevant data structures (trees, heaps, hash tables).
- Tackle harder problems involving shortest paths, network flow, and spanning trees.

## Phase 5: Interview Simulation & Review (ongoing)
- Use `04-practice/02-challenges` to track mock interviews and timed sessions.
- Revisit weak spots flagged during practice.
- Keep a running log of mistakes and improvements.

## Weekly Ritual
- 2x focused study sessions on new material.
- 1x review session where you revisit notes and re-implement previously learned structures/algorithms.
- 1x timed practice block pulling from `04-practice/02-challenges`.

Be consistent, iterate on tough concepts, and celebrate incremental wins.
