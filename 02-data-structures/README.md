# Data Structures Overview

Study the sections in the order presented here. For each topic:
1. Read the overview README.
2. Implement the structure from scratch.
3. Solve the suggested practice problems.
4. Answer the self-check questions without looking back at notes.

## Study Order
1. `01-linear/01-arrays`
2. `01-linear/02-linked-lists`
3. `01-linear/03-stacks-queues`
4. `02-non-linear/01-trees`
5. `02-non-linear/02-heaps`
6. `02-non-linear/03-hash-tables`
7. `02-non-linear/04-graphs`

## Learning Milestones
- Understand how each structure stores data and what operations it optimizes.
- Be able to derive the time/space complexity for CRUD operations.
- Know at least two real-world use cases and one canonical interview problem per structure.
- Implement each structure in your chosen language without referencing documentation.

## Suggested Activities
- Create flashcards for operation complexities.
- Build visualizations or draw diagrams for tree and graph traversals.
- Compare implementations across languages (e.g., Python list vs. C++ vector).

Keep notes in `04-practice/01-patterns` so you can quickly refresh concepts later.
