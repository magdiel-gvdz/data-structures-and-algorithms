# Non-Linear Data Structures

Non-linear structures organize data hierarchically or as networks, enabling powerful traversal and query strategies.

## Topics Covered
- `01-trees/` (binary, balanced variants, tries)
- `02-heaps/` (priority queues)
- `03-hash-tables/` (hash maps, sets, collision strategies)
- `04-graphs/` (directed/undirected, weighted)

## Learning Goals
- Understand traversal algorithms (DFS, BFS, priority-based)
- Know when to choose each structure and the complexity of core operations
- Implement key variations (e.g., AVL rotations, min-heapify)

## Practice Ideas
- Draw diagrams for small examples and walk through operations manually.
- Compare recursion and iteration for tree/graph traversals.
- Build small demos (e.g., autocomplete using a trie, task scheduler using a heap).
