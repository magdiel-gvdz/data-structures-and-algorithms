# Trees

## Key Topics
- Terminology: root, leaf, depth, height, balance factor
- Binary search trees (BST), AVL/Red-Black trees
- Tree traversals (pre/in/post-order, level-order)
- Tries and segment/fenwick trees (stretch goals)

## Must-Implement
- Binary search tree with insert, delete, search
- Balanced BST (AVL or Red-Black) rotations
- Binary tree traversals (recursive and iterative)
- Trie for prefix lookups (optional but recommended)

## Practice Problems
- Validate a BST
- Lowest common ancestor of two nodes
- Serialize/deserialize a binary tree
- Implement a prefix autocomplete using a trie

## Self-Check
- Can you reason about tree height after operations?
- When do you prefer a trie over a hash table?
- How do rotations maintain BST invariants?
