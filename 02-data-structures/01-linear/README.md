# Linear Data Structures

Linear structures store data sequentially. They are the building blocks for more complex abstractions.

## Concepts to Master
- Differences between contiguous (arrays) and linked storage.
- Trade-offs between random access, insertion, and deletion.
- Iteration patterns (forward, backward, sliding windows).
