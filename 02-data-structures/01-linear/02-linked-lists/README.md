# Linked Lists

## Key Topics
- Singly vs. doubly linked lists
- Sentinel nodes and dummy heads
- Fast/slow pointer techniques
- Memory management (manual deallocation vs. GC)

## Must-Implement
- Singly linked list with insert/delete at head, tail, and index
- Doubly linked list with bidirectional traversal
- LRU cache prototype using a doubly linked list and hash map

## Practice Problems
- Reverse a linked list (iterative and recursive)
- Merge two sorted lists
- Remove Nth node from end
- Detect and remove cycle

## Self-Check
- What are the trade-offs between singly and doubly linked lists?
- How do you handle edge cases around head/tail updates?
- How can you make list operations O(1) when deleting a known node?
