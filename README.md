# Data Structures and Algorithms Learning Path

Welcome! This repository is organized as a self-paced curriculum to help you build a solid foundation in data structures and algorithms (DSA). Each directory contains a README that outlines key concepts, suggested study resources, and hands-on exercises.

## Where to Start
- Review the `00-roadmap/README.md` to see the recommended multi-phase plan.
- Work through the `01-foundations/README.md` to make sure core prerequisites are rock solid.

## Directory Overview
- `00-roadmap/` - Big-picture learning plan with pacing guidance.
- `01-foundations/` - Complexity analysis, math refreshers, and coding fluency drills.
- `02-data-structures/` - Structured deep dives into linear and non-linear data structures.
- `03-algorithms/` - Classic paradigms, graph algorithms, and searching/sorting strategies.
- `04-practice/` - Problem-solving patterns, daily drills, and challenge trackers.
- `05-resources/` - Curated list of references, playlists, and communities.

## How to Use This Repo
1. Follow the roadmap checkpoints and only move on when each milestone feels comfortable.
2. For every topic, read the overview, implement the data structure or algorithm from scratch, and solve the suggested practice problems.
3. Track your progress in the practice checklist to keep momentum and spot gaps.

Consistent, deliberate practice wins. Keep iterating on the fundamentals, and revisit sections as needed when tackling harder problems.
