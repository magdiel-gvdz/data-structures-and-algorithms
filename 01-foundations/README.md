# Foundations

Master these fundamentals before diving deep into data structures and algorithms. Revisit as needed whenever new topics feel shaky.

## 1. Complexity Analysis
- Review Big-O, Big-Theta, and Big-Omega notation.
- Practice deriving time and space complexity for loops, recursion, and nested operations.
- Suggested drills:
  - Annotate the complexity for five functions you wrote recently.
  - Explain the difference between amortized and average complexity aloud.

## 2. Math Refresher
- Focus on logarithms, combinatorics, and basic probability.
- Work through a handful of recurrence relations using the Master Theorem.
- Resources: MIT OCW 6.042J notes, Khan Academy logarithms playlist.

## 3. Language Fluency
- Choose one main language for practice (e.g., Python, Java, C++).
- Implement the following helpers without peeking at libraries:
  - Dynamic arrays (resizable vector)
  - Linked list node class with insert/delete
  - Recursion examples (factorial, Fibonacci with memoization)
- Build a cheat sheet of syntax pitfalls and idioms in `04-practice/01-patterns`.

## 4. Tooling & Workflow
- Configure your debugger and learn how to step through recursive calls.
- Set up unit testing (e.g., pytest, JUnit, Google Test).
- Automate linting/formatting to remove friction during coding sessions.

## 5. Baseline Problems
- Two-sum, valid parentheses, merge two sorted lists, binary search.
- Solve each problem twice: once slowly to ensure understanding, once timed.
- Track solutions and notes in `04-practice/02-challenges`.

When you can comfortably explain and implement everything above without reference material, proceed to the data structures section.
