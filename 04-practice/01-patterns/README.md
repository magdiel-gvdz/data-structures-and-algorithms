# Patterns & Templates

Use this space to capture reusable problem-solving blueprints. Update entries after each practice session.

## Suggested Sections
- Sliding window patterns (fixed, dynamic, bidirectional)
- Two-pointers (same/opposite direction, fast/slow)
- Prefix sums and difference arrays
- Recursion templates (DFS, backtracking)
- Dynamic programming state designs

## How to Document
- Problem signature (inputs/outputs, constraints)
- Trigger words from prompts that hint at the pattern
- Pseudocode or skeleton implementation
- Pitfalls and common bugs

## Maintenance Tips
- Reference the date of last review.
- Link related problems stored in `04-practice/02-challenges`.
- Highlight optimizations (space reductions, better base cases).
