# Challenges Log

Track every problem you attempt. Reviewing this log regularly will reveal patterns in mistakes and progress.

## Recommended Columns
- Date
- Problem name & source (LeetCode #, HackerRank, etc.)
- Topic/pattern
- Difficulty (E/M/H)
- Outcome (Solved / Retry / Revisit)
- Notes & follow-up actions

## Usage Tips
- Record time spent and number of attempts.
- Tag problems that exposed gaps in understanding.
- Schedule revisit dates for problems marked "Revisit".
- Summarize weekly learnings at the bottom of this file or in a separate journal.

Consider exporting this log to a spreadsheet if you prefer visual dashboards.
